Admin onboarding

The first-session journey for a brand-new Organization Admin: from sign-in to a running, backed-up workspace, with the onboarding UI screens that carry each step. The working prototype lives separately.

1 · Onboarding scenario

Who onboards, what starts it, and what done means — the context the flow below runs in.

Persona

role: Organization Admin

A brand-new admin in their first session; the role switcher stands in for real authentication.

Trigger

fresh sign-in

Workspace seeded with IMS and Sales Operation live; the four extra modules start deactivated.

Goal

zero to running

Modules live, pipeline rules defined, first clean run, backup scheduled — without leaving the workspace.

Done when

checklist 4 of 4

Setup checklist complete, attention list clear, activity feed showing the first run and the first snapshot.
